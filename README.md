# rain-forcast

ระบบแดชบอร์ดเฝ้าระวังน้ำท่วมจากปริมาณน้ำฝน — **สวนอุตสาหกรรมเครือสหพัฒน์ ศรีราชา** (จ.ชลบุรี)

แดชบอร์ดเรียลไทม์แสดงปริมาณน้ำฝนสะสม ย้อนหลังตั้งแต่อาทิตย์ที่แล้วและต่อเนื่องไป พร้อมกราฟ แผนที่เรดาร์
และระบบแจ้งเตือน (LINE / อีเมล) โดยรวมข้อมูลทั้ง **ภายใน** (เซนเซอร์สวนฯ ผ่าน MQTT/HTTP/CSV)
และ **ภายนอก/หน่วยงานราชการใกล้เคียง**

## แหล่งข้อมูล

- กรมอุตุนิยมวิทยา (TMD API) — สถานี ศรีราชา/ชลบุรี/พัทยา/สัตหีบ/เกาะสีชัง, ฝนรายวัน, ประกาศเตือน
- Open-Meteo — ฝนรายชั่วโมงย้อนหลัง + พยากรณ์ ณ พิกัดสวนฯ
- เรดาร์ฝนหลวง สถานีสัตหีบ (กรมฝนหลวงและการบินเกษตร) + RainViewer (แผนที่เรดาร์)
- เซนเซอร์น้ำฝนภายในสวนฯ — MQTT / HTTP POST / CSV (เปิดใช้ทีละส่วนได้)

## เริ่มใช้งาน

```bash
cd rain-dashboard
npm install
npm start        # → http://localhost:8080
```

ตั้งค่าเพิ่มเติม (MQTT, LINE, อีเมล, คีย์หน่วยงาน): คัดลอก `.env.example` เป็น `.env` แล้วแก้ค่า

รายละเอียดทั้งหมด: [rain-dashboard/README.md](rain-dashboard/README.md)
