# 🌧 แดชบอร์ดเฝ้าระวังน้ำท่วมจากปริมาณน้ำฝน
### สวนอุตสาหกรรมเครือสหพัฒน์ ศรีราชา (จ.ชลบุรี)

แดชบอร์ดเรียลไทม์แสดงปริมาณน้ำฝนสะสม ย้อนหลังตั้งแต่อาทิตย์ที่แล้วและต่อเนื่องไป
รวมแหล่งข้อมูล **ภายใน** (เซนเซอร์สวนฯ) และ **ภายนอก/ราชการ** ในพื้นที่ใกล้เคียง

---

## เริ่มใช้งาน

```bash
cd rain-dashboard
npm install
npm start
# เปิด http://localhost:8080
```

**deploy ขึ้นเซิร์ฟเวอร์ (AApanel + Cloudflare)** → ดู [docs/deploy-aapanel.md](docs/deploy-aapanel.md)
(ได้ชื่อเว็บแบบ `https://saha-rain-watch.<โดเมนของคุณ>`)

ตั้งค่า (ไม่บังคับ — ใช้ค่าเริ่มต้นได้ทันที):

```bash
copy .env.example .env
# แก้ค่าตามต้องการ แล้วรีสตาร์ท
```

## แหล่งข้อมูล

| แหล่งข้อมูล | ประเภท | ใช้ทำอะไร | คีย์ |
|---|---|---|---|
| **กรมอุตุนิยมวิทยา** (TMD API) | ราชการ | ฝน 3 ชม./24 ชม. รายสถานีใกล้เคียง (แหลมฉบัง, ชลบุรี, พัทยา, สัตหีบ, เกาะสีชัง), ฝนรายวันจ.ชลบุรี/ระยอง, ประกาศเตือน | ชุด `demo` ใช้ได้เลย / คีย์จริงที่ data.tmd.go.th |
| **Open-Meteo** (ERA5 + พยากรณ์) | สาธารณะ | ฝนรายชั่วโมง **ย้อนหลัง → ปัจจุบัน → พยากรณ์ 7 วัน** ที่พิกัดสวนฯ (ไม่ต้องคีย์, มี CORS) | ไม่ต้อง |
| **เรดาร์ฝนหลวง สถานีสัตหีบ** (กรมฝนหลวงฯ) | ราชการ | ภาพเรดาร์ CAPPI ทุก 6 นาที (แอนิเมชันในหน้าเว็บ) | ไม่ต้อง |
| **RainViewer** | สาธารณะ | ชั้นเรดาร์ซ้อนแผนที่ (tiles + nowcast) | ไม่ต้อง |
| **เซนเซอร์ภายในสวนฯ** | ภายใน | ฝนจากในสวนฯ ผ่าน MQTT / HTTP POST / CSV | – |
| กรมทรัพยากรน้ำ (telemetry/EWS), กรมชลประทาน | ราชการเสริม | ใส่คีย์ใน `.env` เมื่อลงทะเบียน | ต้องลงทะเบียน |

> หมายเหตุ: TMD จำกัด CORS ระบบจึงมีเซิร์ฟเวอร์ proxy (`server.js`) รับคำขอแทนเบราว์เซอร์

## ช่องทางรับข้อมูลเซนเซอร์ภายใน (เปิดทีละส่วนได้)

### 1) MQTT — เปิดเมื่อพร้อม
```
# ใน .env
MQTT_BROKER=mqtt://< broker >:1883
MQTT_TOPIC=rain/< ของคุณ >
MQTT_FIELD_PATH=mm            # เส้นทางค่าฝนใน payload JSON
MQTT_TIMESTAMP_FIELD=timestamp
```
รีสตาร์ทเซิร์ฟเวอร์ ระบบจะเชื่อมต่อและเก็บค่าอัตโนมัติ

### 2) HTTP POST — ใช้ได้ทันที
```bash
curl -X POST http://localhost:8080/api/internal/rain \
  -H "content-type: application/json" \
  -d "{\"mm\": 2.5, \"timestamp\": \"2026-09-25T14:00:00+07:00\"}"
```
- ส่งหลายค่าพร้อมกัน: array ของ object ก็ได้
- ถ้าตั้ง `INTERNAL_TOKEN` ต้องส่ง header `x-internal-token: <token>`
- `INTERNAL_MODE=cumulative` ระบบแปลงจากตัวเลขสะสมเป็นค่าต่อครั้งให้

### 3) CSV — ผ่านปุ่มในหน้าเว็บ
รูปแบบ: แถวแรก `timestamp,mm` ตามด้วยข้อมูล

### โหมดข้อมูลจำลอง
หากยังไม่มีข้อมูลจริง ระบบจะสร้างข้อมูลจำลอง (มีป้ายกำกับชัดเจน) เพื่อให้เห็นหน้าจอครบทันที
ปิดด้วย `INTERNAL_DEMO_WHEN_EMPTY=false`

## การแจ้งเตือน (เปิดใช้ภายหลัง)

กฎเตือนแก้ไขได้จากหน้าเว็บ (ค่าเริ่มต้น)

| กฎ | เกณฑ์เริ่มต้น |
|---|---|
| ฝนสะสม 24 ชม. (พื้นที่สวนฯ) | > 60 มม. |
| ฝนสะสม 7 วัน | > 150 มม. |
| ฝนในชั่วโมงล่าสุด | > 30 มม./ชม. |
| เซนเซอร์ภายในขาดสัญญาณ | > 15 นาที |

**เปิดช่องทาง LINE** (LINE Messaging API — *LINE Notify ยุติบริการแล้ว*)
1. สร้าง Official Account → เปิด Messaging API → สร้าง Channel Access Token
2. เอา userId/groupId ของผู้รับใส่ `LINE_TO` (คั่นด้วย `,`)
3. `LINE_ENABLED=true` แล้วรีสตาร์ท → ปุ่ม "ทดสอบส่ง" ในหน้าเว็บ

**เปิดช่องทางอีเมล**: กรอก `SMTP_*` + `ALERT_EMAIL_TO` + `EMAIL_ENABLED=true`

ทั้งสองช่องทางมี cooldown กันสแปม (`NOTIFY_COOLDOWN_MIN`, ค่าเริ่มต้น 60 นาที)
และมี "ประวัติการส่ง" ให้ดูในหน้าเว็บ

## หน้าเว็บประกอบด้วย

- **KPI**: ฝนชั่วโมงล่าสุด · ฝนสะสม 24 ชม. · **ฝนสะสม 7 วัน (ตั้งแต่อาทิตย์ที่แล้ว)** · ฝนจากเซนเซอร์ภายใน · สถานีราชการใกล้สุด · สถานะแหล่งข้อมูล
- **กราฟ**: รายชั่วโมง + เส้นสะสม (ย้อนหลัง/ปัจจุบัน/พยากรณ์), รายวัน เปรียบเทียบแหล่งภายนอก vs ภายใน, สถานีใกล้เคียง, สะสมรายวัน
- **แผนที่**: ตำแหน่งสวนฯ + หมุดสถานี + ชั้นเรดาร์ RainViewer
- **ภาพเรดาร์ฝนหลวง** แอนิเมชัน (สัตหีบ)
- **ตารางสถานีกรมอุตุฯ**, ประกาศเตือน, สถานะแหล่งข้อมูล, กฎแจ้งเตือน, ช่องทางส่ง, นำเข้า CSV

ระบบเก็บข้อมูลลง `data/` (JSONL/JSON) — รีสตาร์ทแล้วข้อมูลย้อนหลังไม่หาย
และดึงข้อมูลอัตโนมัติทุก 5 นาที (ปรับผ่าน `REFRESH_*_MS`)

## โครงสร้าง

```
rain-dashboard/
├── server.js              # HTTP server + proxy + background jobs + แจ้งเตือน + รับข้อมูล
├── lib/
│   ├── config.js          # อ่าน .env + ค่าตั้งระบบทั้งหมด
│   ├── store.js           # เก็บ/อ่านข้อมูลรายกาล (JSONL)
│   ├── notify.js          # กฎเตือน + LINE + อีเมล + cooldown
│   ├── sources/
│   │   ├── openmeteo.js   # ย้อนหลัง + พยากรณ์ (รายชั่วโมง)
│   │   ├── tmd.js         # กรมอุตุฯ: สถานี, ฝนรายวัน, เตือนภัย
│   │   └── radar.js       # RainViewer + เรดาร์ฝนหลวง
│   └── ingest/
│       ├── mqttIngest.js  # สมัคร MQTT (เปิดในภายหลัง)
│       └── internal.js    # สรุป/นำเข้า CSV/โหมดจำลอง
├── public/                # หน้าเว็บ (index.html, app.js, styles.css)
└── data/                  # ข้อมูลสะสม (สร้างอัตโนมัติ)
```

## หมายเหตุ

- ข้อมูล Open-Meteo เป็นแบบจำลองบรรยากาศ (grid) — ใช้ดูแนวโน้ม/เปรียบเทียบ;
  ค่าสถานีจริงจากกรมอุตุฯ แสดงแยกในตารางและ KPI
- หน่วยทั้งระบบเป็น **มม.** เวลาเป็น **เวลาไทย (ICT)**
- ใช้ CDN สำหรับ Chart.js/Leaflet/แผนที่ — ต้องมีอินเทอร์เน็ตตอนเปิดหน้าเว็บ
